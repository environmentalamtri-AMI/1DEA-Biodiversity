# 1DEA Biodiversity

Standalone biodiversity microsite derived from the 1DEA ecosystem for AlamTri Geo.

## GitHub Pages deployment
1. Create a new repository, suggested name: `1dea-biodiversity`.
2. Upload **all files and folders in this ZIP to the repository root**.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Branch: `main`, folder: `/ (root)`.
6. Save and wait for deployment.

The trial URL will look like:
`https://<github-username>.github.io/1dea-biodiversity/`

After the GitHub trial is approved, the site can later be connected to a subdomain such as `biodiversity.enviroamc.com`.

## Current scope
- Overview / inventory summary
- Interactive species explorer
- Search and conservation-status filtering
- Species detail modal
- Conservation programs
- Conservation-status reference
- Responsive desktop / tablet / mobile design

## Data basis
Current content is based on the biodiversity material already incorporated into the 1DEA biodiversity module. The site can later be expanded with the complete species catalogue, GIS layers, monitoring dashboards, and additional program documentation.
